# Gravel Outfit 0.23.1

Die automatische Empfehlung plant einen gemeinsamen Baselayer. Wenn die Rückfahrt einen Baselayer benötigt, wird er schon auf dem Hinweg getragen. Andernfalls bleibt der Baselayer aus einem früheren Abschnitt an. Die App weist auf Abweichungen vom persönlichen Temperaturbereich hin.
